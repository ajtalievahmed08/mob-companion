# MOB Companion project website

Static project landing page for GitHub Pages.

## Publish with GitHub Pages

1. Create a **public** repository named `mob-companion-site` in the account that owns the project.
2. Upload the contents of this folder to the repository root (make sure `index.html` is at the root, not inside another nested folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then Save.
6. Wait for the Pages deployment and open the URL shown in Settings → Pages. For a project repository this normally has the form `https://USERNAME.github.io/mob-companion-site/`.
