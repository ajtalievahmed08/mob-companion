PRIVACY OVERVIEW

Privacy, in plain words.

This page describes the current prototype direction. It is not a final legal privacy policy for a public release.

01

Current prototype

The local browser prototype stores interface preferences such as mascot position, appearance, and settings in browser extension storage. It does not require a MOB account.

02

Game data

Future data features are planned to use supported FACEIT developer interfaces. Exact data fields, processing, retention, and permissions will be documented before those features are released.

03

No game-process access

MOB is intended as a browser companion. It is not designed to read CS2 memory, interfere with the game client, bypass anti-cheat, or automate gameplay.

04

Contact and requests

Public support and privacy contact details will be added before a wider release.

MOB Companion is an independent, unofficial community project and is not affiliated with or endorsed by FACEIT.
